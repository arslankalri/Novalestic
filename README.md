# NOVALESTIC JEWELLERS

NOVALESTIC is a public-facing jewellery storefront project focused on a refined, mobile-friendly browsing and cart experience for customers viewing jewellery priced in Pakistani rupees (PKR).

## Current status

The site is a design preview. Product names, images, descriptions, specifications and prices are sample content, not confirmed inventory or live offers. The cart is a local front-end preview only. There is no checkout, order submission, payment processing, customer account, admin portal, owner mode or order-management interface in this public-site application.

## Development

This project uses React, TypeScript, Vite and Tailwind CSS. Install dependencies using the package manager and lockfile included in the repository, then run the scripts defined in `package.json`.

```sh
npm install
npm run dev
npm run build
npm run lint
```

The public storefront should not contain private management controls or secrets. A separate authenticated admin application can be designed independently in the future.
